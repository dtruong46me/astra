# JLPT N2 – đề luyện có giải thích

Mỗi đề là một trang HTML tự chứa: làm bài, chấm điểm, và mở giải thích từng câu
(đáp án, dịch câu, Hán Việt, cách đọc, phương án nhiễu, ngữ pháp, ghi chú).

- `exams/*.json` – nội dung đề + giải thích (nguồn: DORA Nihongo, Google Drive)
- `template.html` – giao diện chung
- `siblings.json` – link các trang đã xuất bản để liên kết chéo
- `python3 build.py` → `dist/<id>.html`
